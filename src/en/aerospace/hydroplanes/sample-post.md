## How to write a post

A post is a plain text file in Markdown. It starts with a header between two `---` lines (title, description, date, tags). The text follows below.

- bullets start with a dash,
- **bold text** goes between two asterisks,
- a [link](/en/archive/) uses square and round brackets.

## Images

Insert an image with a line that has the **image description** in square brackets (required, for screen readers and search engines) and the file path in round brackets:

```
![Image description](/assets/img/file-name.jpg)
```

Save the image file in `src/assets/img/`. For each image, I recommend noting the source and licence.
